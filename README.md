# QALA — «Аким на 5 часов»

AI-симулятор управления городом для HackAlem AI (команда **Latitude51N**).

Пользователь получает бюджет **100** и принимает **ровно 5 решений** из каталога 14 мероприятий. Симулятор показывает, как меняются пять условных районов, и считает **Astana Quality of Life Score**. Баллы считает детерминированный код; OpenAI объясняет готовый результат: сильные стороны, риски, компромиссы. Отдельная функция **«Улучшить одно решение»** перебирает все допустимые замены одной меры и предлагает лучшую.

Материалы задачи: [ТЗ](https://docs.google.com/document/d/1oDZtYnBgbcn_Ii7vleP87hkARJ2HmbXl7Cw_rsCxqpo/edit), [датасет и формула](https://docs.google.com/document/d/1Uc-GdGoKhDY-spu8V50-ZMm33t2CjYLP/edit). Сводка для разработки — [`HACKALEM_BRIEF.md`](./HACKALEM_BRIEF.md).

## Запуск

Нужен Node.js 20+.

```bash
npm install
cp .env.local.example .env.local   # впишите OPENAI_API_KEY
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Без ключа работает всё, кроме AI-разбора: кнопка «Объяснить сценарий» покажет, что ключа нет.

| Команда | Что делает |
|---------|-----------|
| `npm test` | 18 тестов движка: контрольные значения и все правила |
| `npm run build` | production-сборка с проверкой типов |
| `npm run lint` | ESLint |

## Проверка математики

| Кейс | Ожидание | Где проверяется |
|------|----------|-----------------|
| Без действий | **52.55768** | `npm test`, «control values» |
| Пример организаторов: M7 Нура, M8 Нура, M10 Нура, M12 город, M5 Сарыарка (стоимость 95) | **56.54307**, синергия M10+M12 | `npm test` и кнопка «Загрузить пример организаторов» |
| Самый дешёвый допустимый набор M9, M11, M10, M12, M4 | стоимость 61, допустим | `npm test` |

Также тестами покрыты: ровно 5 мер, запрет повторов, бюджет, максимум 2 меры на направление, обязательный район для районных мер и запрет района для городских, несовместимости M1↔M3, M4↔M7 и M5↔M13 в одном районе, независимость от порядка, лаг `(8 − L) / 8`, применение городских мер ко всем районам.

## Демо-сценарий

1. «Загрузить пример организаторов» — Score 56,54307, на схеме подсвечены Нура и Сарыарка, видна синергия M10+M12.
2. «Найти лучшую замену» — программа показывает, какую меру заменить, прирост Score, какой район выиграл и какой потерял. «Применить замену» переносит её в план.
3. «Объяснить сценарий» — AI-разбор готового расчёта.
4. Меры, на которые не хватает бюджета или которые нарушают правила, недоступны, и рядом написана причина. Если план стал недопустимым (например, M4 перенесли в район, где уже стоит M7), Score не считается и выводится причина.

## Модель

1. Новое значение показателя: `I' = clip(I + Σ эффект × (8 − L) / 8 + синергии, 0, 100)`. Районные меры действуют в выбранном районе, городские — во всех пяти. Синергии фиксированные и лагом не масштабируются.
2. Оценка района: `D = Σ w_k × I'_k`.
3. `Score = 0,7 × D_avg + 0,3 × min(D) − N_crit`, где `D_avg` взвешен по населению, `N_crit` — число пар «район × показатель» строго ниже 40.

## Архитектура

```
src/lib/engine/        данные, валидатор, расчёт Score, перебор замен, тесты
src/components/        схема районов (SVG), конструктор плана, результаты
src/app/api/analyze/   серверный AI-разбор
```

Один валидатор используется везде: для Score, для подсказок, почему мера недоступна, для перебора замен и на сервере. `/api/analyze` принимает только список решений, сам пересчитывает Score и лучшую замену и передаёт модели готовые числа. Результату, пришедшему из браузера, сервер не доверяет. Ключ OpenAI живёт только на сервере.

Стек: Next.js 16 (App Router), TypeScript, Tailwind CSS 4, Motion (с учётом `prefers-reduced-motion`), Vitest, OpenAI Chat Completions API.

Весь код написан на хакатоне; сторонние UI-компоненты не копировались. Схема районов условная, это не карта Астаны.
