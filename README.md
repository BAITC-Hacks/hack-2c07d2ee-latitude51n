# QALA — «Аким на 5 часов»

Симулятор управленческих решений для хакатона BAITC (команда **Latitude51N**).

Вы выбираете **ровно 5 мероприятий** при бюджете **100**, видите влияние на пять условных районов и получаете **Astana Quality of Life Score**. Баллы считает код; ИИ только объясняет готовый результат. Демо-фича: **«Улучшить одно решение»**.

## Контрольные значения

| Кейс | Ожидание |
|------|----------|
| Базовый Score (без действий) | **52.55768** |
| Пример организаторов (стоимость 95) | **56.54307** |

Проверка: `npm test`

Пример организаторов в UI: кнопка **«Пример организаторов»**  
(M7 Нура, M8 Нура, M10 Нура, M12 город, M5 Сарыарка).

## Стек

- Next.js 16 (App Router) + TypeScript + Tailwind CSS 4
- Motion (анимации, уважает `prefers-reduced-motion`)
- Vitest — тесты расчётного движка
- OpenAI Chat Completions — серверный AI-разбор (`/api/analyze`)

## Быстрый старт

```bash
npm install
cp .env.local.example .env.local
# впишите OPENAI_API_KEY=...
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Без ключа симулятор и расчёт работают полностью; кнопка «Объяснить сценарий» вернёт понятную ошибку 503.

```bash
npm test      # движок и валидатор
npm run build # production-сборка
```

## Как пользоваться (демо за минуту)

1. Нажмите **«Пример организаторов»** — Score ≈ 56.54307.
2. Посмотрите схему районов: Нура и Сарыарка подсвечены эффектами; синергия M10+M12.
3. **«Объяснить сценарий»** — AI-разбор сильных сторон и компромиссов.
4. **«Найти замену»** → **«Применить»** — одна замена с лучшим найденным Score.
5. Намеренно сломайте правило (например, 3 меры соцсферы) — Score не считается, видна причина.

## Правила модели

- Бюджет 100; ровно 5 мер; без повторов.
- ≤ 2 мер одного направления.
- Лаг: доля эффекта `(8 − L) / 8`.
- Синергии без лага; несовместимости M1↔M3, M4↔M7 (один район), M5↔M13 (один район).
- `Score = 0.7×D_avg + 0.3×min(D) − N_crit`

Подробности датасета и формулы: [`HACKALEM_BRIEF.md`](./HACKALEM_BRIEF.md).
